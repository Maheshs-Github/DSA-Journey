# DSA Journey

A structured collection of data structures & algorithms problems, organized
by topic, tracking daily practice toward interview readiness.

## Why This Repo

Rather than a flat dump of solved problems, this is organized to reflect how
I'm building pattern recognition across topics — the goal isn't just solving
individual problems, but recognizing which technique applies where.
